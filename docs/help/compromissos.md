# Compromissos

## Objetivo

Organizar visitas, lembretes, eventos e tarefas em uma agenda operacional simples.

## Principais funções

- filtrar compromissos por hoje, amanhã, semana ou todos;
- criar compromisso;
- editar compromisso;
- concluir, cancelar ou reabrir;
- acompanhar métricas de pendentes, concluídos e cancelados;
- ver o próximo foco pendente.

## Fluxo de uso

1. Abra `Compromissos`.
2. Escolha o filtro de período.
3. Crie um item com título, tipo, data, hora e observação.
4. Use os botões de ação para editar, concluir, cancelar ou reabrir.

## Dicas

- use títulos objetivos, como `Visita com cliente comprador`;
- mantenha hora preenchida para facilitar a leitura de próximos passos;
- use o bloco `Próximo foco` como referência rápida do que ainda está pendente.

## Limitações atuais

- a criação é feita com poucos campos e não exige vínculos complexos;
- a tela prioriza simplicidade e não mostra uma visualização de calendário mensal completo.

## Mensagens de erro comuns

- `Informe o compromisso.`
- `Não foi possível carregar os compromissos.`
- `Não foi possível salvar o compromisso.`
- `Não foi possível atualizar o compromisso.`

## Melhores práticas

- registre só o essencial para manter a agenda rápida;
- conclua ou cancele itens no mesmo dia para manter a fila confiável;
- reabra apenas compromissos que realmente voltaram a ficar pendentes.
