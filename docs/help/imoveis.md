# Imóveis

## Objetivo

Gerenciar a carteira de imóveis do corretor, incluindo edição comercial, cadastro jurídico, mídia, publicação e apoio de IA.

## Principais funções

- listar imóveis;
- filtrar por busca, status, tipo e faixa de preço;
- abrir e editar imóvel em modal;
- publicar e despublicar;
- subir e remover imagens;
- escolher imagem principal;
- subir e remover áudio;
- preencher dados jurídicos e documentos;
- gerar descrição com IA.

## Fluxo de uso

1. Abra `Imóveis`.
2. Use a busca e os filtros para localizar o ativo.
3. Clique no imóvel para abrir a edição completa.
4. Atualize dados gerais, descrição, mídia e cadastro jurídico.
5. Salve as alterações.
6. Publique ou mova para rascunho conforme a estratégia da carteira.

## Dicas

- use `Buscar CEP` também no cadastro jurídico do imóvel;
- mantenha matrícula, cartório e áreas preenchidos para facilitar contratos;
- posicione a melhor foto como imagem principal;
- use `Gerar descrição com IA` depois de preencher informações básicas do imóvel.

## Limitações atuais

- o plano pode limitar a quantidade de imóveis publicados;
- a área de `Gravação em breve` aparece na edição, mas a gravação direta ainda não está ativa;
- o envio de documentos jurídicos usa anexação na própria tela de edição.

## Mensagens de erro comuns

- `Não foi possível enviar as imagens.`
- `Não foi possível remover a imagem.`
- `Não foi possível atualizar a imagem principal.`
- `Não foi possível salvar as alterações.`
- `Não foi possível localizar o CEP.`
- `Não foi possível gerar a descrição com IA.`
- `Não foi possível excluir o imóvel.`

## Melhores práticas

- publique apenas imóveis com boa foto, preço e descrição;
- complete o bloco jurídico antes de gerar contratos;
- use rascunho enquanto o imóvel ainda estiver incompleto.
