# Primeiros passos

## O que é o EME

O EME é o Sistema Operacional do Corretor. Mais do que um CRM, ele centraliza toda a operação imobiliária em uma única plataforma — clientes, imóveis, propostas, contratos, campanhas, agenda e desempenho — de forma integrada.

O grande diferencial do EME é o COS (Conversation Operational System), um operador conversacional que executa tarefas reais dentro do sistema a partir de comandos em linguagem natural, além de orientar o corretor durante a rotina.

## Depois de criar a conta

Ordem recomendada para começar a operar:

1. configurar a conta (`Conta` e `Segurança`);
2. cadastrar os primeiros clientes;
3. adicionar os imóveis;
4. publicar o catálogo;
5. usar o COS para acelerar as tarefas do dia a dia.

Todo o sistema pode ser utilizado tanto conversando com o COS quanto navegando pelos módulos diretamente.

## Objetivo

Explicar como entrar no EME, criar a conta de corretor e começar a usar o portal do corretor.

## Principais funções

- criar conta de corretor individual;
- entrar com email e senha;
- entrar com PIN quando já configurado;
- usar biometria quando o dispositivo confiável e a biometria estiverem ativos;
- recuperar senha por fluxo visual de solicitação.

## Fluxo de uso

1. Acesse `/cadastro`.
2. Hoje, o cadastro público está focado em `Corretor individual`.
3. Preencha nome, email, WhatsApp, CRECI e senha.
4. Após criar a conta, o sistema direciona para a área do corretor.
5. No login, escolha `Email e senha` ou `Entrar com PIN`.
6. Se houver biometria disponível no dispositivo confiável, o botão biométrico também aparece.

## Dicas

- cadastre um WhatsApp válido com DDD, porque ele é reutilizado em catálogo e contato;
- complete o CRECI já no cadastro para evitar ajustes logo no primeiro acesso;
- depois do primeiro login, revise `Conta` e `Segurança`.

## Limitações atuais

- o fluxo público de cadastro está focado em corretores individuais;
- a área de imobiliárias existe em rotas próprias, mas hoje a interface mostra que essa área está em evolução;
- o botão `Continuar com Google` está presente no login, mas o comportamento implementado na tela é apenas visual;
- a recuperação de senha exibe feedback de solicitação, mas o próprio texto da tela informa que a integração com backend ficará válida quando conectada.

## Mensagens de erro comuns

- `Não foi possível criar sua conta agora.`
- `Não foi possível validar sua sessão agora. Tente recarregar a página.`
- mensagens de erro de login vindas do fluxo de autenticação.

## Melhores práticas

- use um dispositivo confiável só em aparelhos pessoais;
- configure PIN e biometria depois do primeiro acesso;
- confirme se o redirecionamento após login levou você para a área correta do corretor.
